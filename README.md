Product Inventorya & Catalog System
Core Skills Practiced: OOP principles (Encapsulation, Inheritance), List, Map, sorting, and filtering.

Problem Definition: Build a command-line inventory management system. Create a Product class 
(id, name, price, category, stockQuantity).
 Use an Inventory class that stores products in a HashMap<String, Product> (keyed by product ID) and a List<Product>.

Key Tasks: Implement methods to add products, update stock, search by category, and sort products by price (using Comparator).
